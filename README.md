# Smart Navigation and Obstacle Detection System for Visually Impaired Users

## Project Overview

This project is being developed as part of the Senior Design course at the University of Texas at Dallas (UTD).

Our goal is to design and develop an assistive navigation device that helps visually impaired users navigate their surroundings more safely and independently.

The proposed system combines GPS navigation, obstacle detection, computer vision, and real-time audio or haptic feedback.

## Project Objectives

- Provide GPS-based navigation assistance.
- Detect obstacles and potential hazards in the user's surroundings.
- Identify relevant objects using computer vision and AI.
- Estimate obstacle distances using depth sensing and/or LiDAR.
- Deliver real-time alerts through audio and/or haptic feedback.
- Develop a practical prototype within the project budget.

## Proposed Hardware and Technologies

The following components are currently under evaluation:

| Component | Purpose |
|---|---|
| NVIDIA Jetson Orin Nano / Orin Nano Super | Edge AI processing and computer vision |
| Depth Camera | Depth estimation and visual object detection |
| LiDAR / Radar | Obstacle detection and distance measurement |
| GPS Module | Location tracking and navigation |
| Microphone | Potential voice input |
| Speaker / Haptic Motor | User feedback and hazard alerts |

Final component selections have not yet been made.
